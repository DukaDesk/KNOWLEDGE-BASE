# TASK-0026: Integrate customizable dashboard endpoint in dukaDesk frontend

## Parent Feature

- [FEAT-0008 Customizable Merchant Dashboard](../features/FEAT-0008.md)

## Engineering Specification

- [UI-0004 Tenant Dashboard Foundation and Shell](../../engineering-specifications/specifications/ui/UI-0004.md)

## Repository Target

- dukaDesk/

## Description

Consume the backend dashboard endpoint in `dukaDesk/src/components/pages/Dashboard.jsx` and `src/runtime/VerticalContext.jsx`, replacing the purely local `verticalPresetModules` + `getDashboardModules()` rendering path with backend-resolved widget data.

> **Implementation note (2026-10-30):** TASK-0025 shipped the analytics dashboards API (`GET/POST /api/v1/analytics/dashboards`, `GET /api/v1/app/analytics/dashboards/:id/data`, widget CRUD) instead of the originally specified `GET /api/v1/merchants/:id/dashboard` returning `{kpis, quickActions, widgets, enabledModules, layout}`. This task integrates the endpoint that actually exists: `Dashboard.jsx` bootstraps a default dashboard, reconciles its widgets with the enabled module set, and renders live widget data. `kpis`/`quickActions` remain vertical-config driven (the shipped endpoint does not return them).

## Acceptance Criteria

- [x] `VerticalContext` resolves enabled modules on mount and notifies the dashboard of changes (`EventBus` `modules:changed`); dashboard bootstraps `GET /api/v1/analytics/dashboards` with fallback to local presets when offline/demo. (Adapted: specified `/merchants/:id/dashboard` endpoint was not built.)
- [x] `Dashboard.jsx` renders `widgets` from the endpoint response (metric strip, revenue-trend chart, recent orders, top products); `kpis`/`quickActions` stay vertical-config driven until an endpoint provides them.
- [x] When `Integrations.jsx` toggles a tool, `VerticalContext` emits `modules:changed` and the dashboard resyncs backend widgets (create/remove by metric) without a page reload.
- [ ] E2E: enable/disable a tool → dashboard widgets appear/disappear without reload. (Manual verification pending — dev server `localhost:3000`, PR DUKA-MERCHANT#6 merged `9ab36a8`.)
